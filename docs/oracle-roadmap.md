# DAORA · 占卜桌（Oracle Table）功能图与路线图

> 分支：`feature/oracle-table` · 入口：`divination.html` · 仅做自我探索与文化体验，非专业建议。

## 功能图（Feature Map）

```
DAORA · 占卜桌
├── 场景（3D 桌面）
│   ├── 圆桌 + 绒布 + 黄铜环
│   ├── 灯笼（点光源呼吸闪烁）
│   ├── 尘埃粒子（缓慢漂浮）
│   └── 牌叠（12 层，洗牌时抖动）
├── 占卜核心
│   ├── 22 张大阿尔卡那（正位，中英双语名称 + 关键词）
│   ├── 抽牌：每组 3 张，均匀随机不重复
│   ├── 翻牌：点击/轻点 → 抬升 + 前移 + 居中 + 翻转 180°（再点合回）
│   └── 换一组牌：合牌 → 归叠 → 洗牌抖动 → 交错发新牌
├── 交互
│   ├── 拖拽环视（OrbitControls，阻尼 + 极角/距离限制）
│   ├── 滚轮/双指缩放
│   ├── 悬停抬升（桌面端）
│   └── 点按与拖拽区分（位移 < 9px 且 < 450ms 才算点按）
├── 界面
│   ├── 右上：中/EN 切换（localStorage 记忆）
│   ├── 右上：声音开关（Web Audio 全合成音效：翻牌/发牌/洗牌/确认铃）
│   ├── 底部：换一组牌主按钮 + 操作提示 + 免责声明
│   └── 解读条：牌名（中/英）· 罗马数字 · 正位 · 关键词
├── 工程
│   ├── 本地资源：牌面 Canvas 程序化生成，音效全合成，零外链资源
│   ├── 移动端：R0 viewport / 触控翻牌 / 无横向滚动 / 安全区适配
│   ├── 无障碍：aria-live 解读区、focus-visible、prefers-reduced-motion 降级
│   └── 验证：tests/oracle-visual.mjs（15 项：控制台零报错、零 404、翻牌、换牌、双语、声音、移动端）
└── 多页构建：vite.config.js 注册 divination 入口，主站 index.html 不受影响
```

## 技术备忘
- 牌面/牌背：`src/divination/textures.js` Canvas 绘制，按 `cardId:lang` 缓存；切语言只换贴图
- 音效：`src/divination/audio.js` Web Audio 合成，首次点击手势后 resume
- 动画：table.js 内置轻量 tween（easeInOutCubic），尊重 prefers-reduced-motion（时长 ×0.35）
- 已知取舍：牌面为极简文字设计而非插画（MVP 控制包体与工期）；逆位未启用
